# prueba_sql_juanruizfernandez
Prueba del Modulo de SQL


DESCRIPCION
Realización de diferentes consultas para demostrar el conocimento del lenguaje SQL aprendido en la formación. 
Se han de demostrar los siguientes conocimientos:

● Manejo de la herramienta DBeaver.
● Manejo de las consultas con una sola tabla de tu BBDD.
● Manejo de las relaciones entre tablas.
● Manejo de las subconsultas.
● Vistas.
● Estructura de datos temporales.
● Buenas prácticas.


ESTRUCTURA DEL PROYECTO

Carpeta 1.- Enunciado -> Contiene el enunciado de la prueba
Carpeta 2.- BBDD -> Aquí podrás encontrar la query para genera la BBDD en Postgres
Carpeta 3.- Ejercicio -> Contiene el diagrama de la BBDD y un script con el enunciado y las consultas generardas
Readme.md -> Descripción del proyecto


INSTALACIÓN Y REQUISITOS

Este proyecto usa el lenguaje SQL y es necesario el programa Dbeaver o uno similar
